# 🚀 Manus AI Prompt — AI Engineer Portfolio / Landing Page

## Objective
Create a modern, minimal **portfolio + landing page** for an AI Engineer.

⚠️ IMPORTANT:
All content (projects, experience, skills, metrics, etc.) MUST be extracted from the uploaded resume PDF. Do not invent or assume anything.

---

## 🎨 Design System
- Colors:
  - #1F6F5F (primary)
  - #2FA084 (secondary)
  - #6FCF97 (accent)
  - #EEEEEE (background)
- Font: Google Sans
- Style: clean, modern, minimal, slightly futuristic

---

## 🧱 Sections Required

1. **Hero**
   - Strong headline
   - Short subtext
   - CTA buttons (Projects, Contact)

2. **About**
   - Short professional summary

3. **Projects**
   - Extract directly from resume
   - Show tech + impact (metrics)

4. **Skills**
   - Grouped (AI, Data, Cloud, etc.)

5. **Experience**
   - Timeline format
   - Focus on impact

6. **Services (Optional but preferred)**
   - Based on skills and work

7. **Contact / CTA**
   - Simple and clear

---

## ⚡ UX Requirements
- Fully responsive
- Smooth scrolling
- Clean layout
- Subtle animations

---

## 🧠 Copy Guidelines
- Keep it concise
- Focus on outcomes and impact
- Avoid buzzwords

---

## 🛠️ Tech (optional)
- React / Next.js + Tailwind preferred

---

## 🧬 Custom Manus Skills

### 1. Resume → Portfolio Converter
- Automatically extract and structure:
  - Projects
  - Experience
  - Skills
- Convert into clean web sections

### 2. Impact Highlighting
- Detect metrics (%, scale, performance)
- Emphasize them visually in UI

### 3. AI Engineer Positioning
- Present profile as:
  - GenAI + Data + Business-focused engineer
